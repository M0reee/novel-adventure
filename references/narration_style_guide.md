# Narration Style Guide

The game should feel like the imported novel without copying long passages.

Extract and reuse:

- Pacing: slow-burn, fast conflict, mystery, comedy, grim pressure.
- Dialogue shape: terse, ornate, sarcastic, formal, sect etiquette.
- Conflict loops: resource scarcity, status pressure, revenge, faction politics, hidden identity.
- Sensory palette: common images, materials, weather, spiritual pressure, combat texture.

Avoid:

- Repeating original prose verbatim beyond short names and terms.
- Turning every scene into exposition.
- Revealing high-level secrets before the player has earned them.
